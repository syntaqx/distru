# What is Distru

Distru is a seed-to-sale ERP for licensed cannabis operators. It runs the whole operation in one place - **cultivation**, **inventory**, **manufacturing**, **sales**, **purchasing**, **compliance**, and **deliveries** - with real, FIFO-costed inventory underneath and an AI **Copilot** that can do the same work through conversation.

## Your workspace
Everything you see belongs to a **workspace** - an isolated organization with its own data, members, and API tokens. The switcher in the top-left shows which workspace you're in; switching it changes every page and the Copilot's context.

## Finding your way
The sidebar is grouped by the way the work flows:

- **Overview** - your **Dashboard**, a **Tasks** board and calendar, and the **Notifications** inbox.
- **Catalog** - **Inventory** (your product catalog and on-hand stock), tagged **Packages**, and **Categories**.
- **Sales & CRM** - **Sales** (orders, invoices, payments), **Returns**, and **Companies** (your CRM).
- **Supply & Production** - **Purchasing** (POs received at cost), **Manufacturing** (assemblies), and **Dispatch** (a live fleet map, the deliveries board, drivers, and vehicles).
- **Grow & Comply** - **Cultivation** (plants to harvest) and **Compliance** (licenses, COAs, and a Metrc view).
- **Automate & Analyze** - **Insights**, **Reports**, and **Automations**.
- **Settings** - members, reference data, API tokens, the API reference explorer, webhooks, integrations, and the audit log.

## The Copilot
Open the Copilot from the top-right or with **Ctrl/Cmd+J**. It reads and changes the same records the pages do, asks before it changes anything, and can make bulk changes in one approval. The same tools are available to your own agent over the [public API and MCP server](/docs/api-and-integrations).
